# Changelog

## 0.1.0 — 2026-09-13

- PostgreSQL durable queue, atomic idempotent batches, REST API, Go CLI and Python SDK.
- Resource-aware placement, leases, heartbeats, retries, cancellation, and fenced results.
- Durable RPC request receipts, append-only attempts/events, concurrent Python workers.
- S3 artifacts, atomic training checkpoints, checksum verification and crash recovery.
- Prometheus/OTLP, Compose deployment, real database/race and fault-injection tests.
- Reproducible scaling, recovery, and 10K/100K queue-pressure evidence.
- Authentic 80-job HeteroSplit adapter; the proposed 160-job grid needs additional
  scientifically valid dataset/regime combinations.
- Published Linux/macOS release archives with checksums and passing hosted CI.
